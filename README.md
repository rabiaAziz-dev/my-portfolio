# My Portfolio

## Project Overview

A clean, responsive portfolio website built with Next.js and TypeScript to showcase projects, experience, skills, and contact information. The site includes modular components (hero, about, experience, projects, skills, contact), a typewriter effect, floating decorative elements, and a responsive navigation/sidebar.

## Features

- **Responsive layout:** Optimized for desktop, tablet, and mobile screens.
- **Sections:** Hero, About, Experience, Projects, Skills, Contact.
- **Interactive UI:** Typewriter effect, floating elements, and shared background components for a polished look.
- **Accessible components:** Reusable UI primitives and focus-friendly navigation.
- **Easy customization:** Tailwind CSS utility classes and modular components make styling and content changes straightforward.

## Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI:** Custom React components (in `components/` and `ui/`)
- **Tooling:** Vercel for deployment

## Setup Instructions

1. Clone the repository

```bash
git clone https://github.com/rabiaAziz-dev/my-portfolio.git
cd my-portfolio
```

2. Install dependencies

```bash
npm install
# or
pnpm install
```

3. Run the development server

```bash
npm run dev
# or
pnpm dev
```

4. Build for production

```bash
npm run build
npm start
# or with pnpm
pnpm build
pnpm start
```
